# Запись с 4G-камер V380 Pro на OpenWrt

Экспериментальный видеорегистратор для 4G-камер, работающих через **V380 Pro** и облачные ретрансляторы. Не требует прямого IP-доступа к камере за CGNAT. Рассчитан на солнечные камеры, которые отключаются при разряде батареи и затем автоматически включаются.

**Подтверждённый тест:** семейство оборудования `HsAKQQCG`, версия протокола устройства `32`, H.265 640×1080. Ролик MP4 с видеодорожкой и аудио был воспроизведён на iPhone. Это не официальное приложение V380, и работа с другими моделями не гарантирована.

## Что умеет

- Записывать короткий MP4 (~25 секунд) каждые 15 минут по cron.
- Продолжать работу после временного отключения камеры или 4G: пропустить неудачный запуск и повторить на следующем интервале.
- Получать поток через relay TCP 8800, собирать фрагменты и расшифровывать H.265 (протокол версии 32).
- Упаковывать H.265 в MP4 без перекодирования и без HEVC-декодера FFmpeg на роутере.
- При наличии FFmpeg добавлять AAC-звук, экспериментально определяя исходные данные как AAC-ADTS или G.711 A-law.
- Хранить архив на USB и удалять **только самые старые MP4 внутри папки архива**, когда достигнут лимит (20 ГиБ) или осталось менее 3 ГиБ свободного места.
- Не писать во внутреннюю flash-память роутера, если USB не смонтирован; не запускать две записи одновременно.

## Установка на OpenWrt (apk)

Нужны `python3`, `python3-cryptodome`, `ca-bundle`, USB-флешка ext4, смонтированная **именно как `/mnt/usb2`**. Для записи со звуком нужен FFmpeg (для видео без звука FFmpeg не обязателен).

```sh
apk update
apk add python3 python3-cryptodome ca-bundle ffmpeg
mount | grep ' on /mnt/usb2 '
```

Создайте файл `/etc/v380_recorder.json` на основе `config.example.json`, заменив демонстрационный `device_id` на свой и `relay_allowlist` на **проверенные** IP-адреса relay-серверов. Демонстрационный `203.0.113.10` не является работающим сервером. Запрос к диспетчеру V380 идёт через HTTP, поэтому серверы специально ограничены списком доверенных адресов.

Сохраните пароль самой камеры в `/etc/v380_camera_password`, задайте права `chmod 600` на оба файла. Пароль не должен храниться в Git, аргументах командной строки или README.

Установка файлов (команда **не перезаписывает** существующий видеорегистратор):

```sh
sh scripts/install-openwrt.sh
python3 /mnt/usb2/V380/v380_cycle_recorder.py
tail -n 30 /mnt/usb2/V380/cycle.log
ls -lh /mnt/usb2/V380/archive/
```

Проверив MP4 на телефоне, включите cron:

```sh
echo '*/15 * * * * /usr/bin/python3 /mnt/usb2/V380/v380_cycle_recorder.py >/dev/null 2>&1' >> /etc/crontabs/root
/etc/init.d/cron enable
/etc/init.d/cron restart
```

Не добавляйте строку повторно, если она уже есть. Настройки часового пояса влияют на названия файлов и другие задания cron.

## Пути и конфигурация

- `/etc/v380_recorder.json` — локальный ID устройства, разрешённые relay-IP, FPS, лимиты архива.
- `/etc/v380_camera_password` — пароль камеры (права `600`).
- `/mnt/usb2/V380/archive/` — ролики MP4.
- `/mnt/usb2/V380/work/` — временные видеоданные, которые очищаются.
- `/mnt/usb2/V380/cycle.log` — журнал попыток.

## Важные ограничения

Протокол экспериментальный, совместимость с другими камерами не подтверждена. FPS в MP4 пока приблизительный (12). HEVC предполагает отсутствие B-кадров; синхронизация звука может отличаться от идеальной. A-law определяется предположительно, сравните реальный звук с V380 Pro. При выключенной солнечной камере пропущенное видео не восстанавливается.

## Конфиденциальность

В репозитории **нет** действующих ID устройства, паролей, SIM/IMEI, видеозаписей или билетов авторизации. Не добавляйте сюда файлы из `/etc`, архивы, логи и скриншоты с QR-кодами. Публикация делается **из отдельного каталога**, не из работающей папки V380.
