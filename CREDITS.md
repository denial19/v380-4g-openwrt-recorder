# Credits and scope of attribution

Independent OpenWrt/Python recorder created through iterative testing on one
owned camera. Protocol implementation informed by public research:

- [PyanSofyan/V380Decoder](https://github.com/PyanSofyan/V380Decoder): V380
  proprietary packet structure, cloud transport and audio/video decryption.
- [j-bloggs/v380-4g-stream](https://github.com/j-bloggs/v380-4g-stream):
  earlier Python experiments with V380 4G relay streams and issue discussions.

Their original source trees are **not bundled** in this repository. The repository's
MIT license applies to independently contributed project code, not vendor
firmware or third-party code. V380 and V380 Pro are third-party trademarks.
